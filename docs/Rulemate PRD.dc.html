1. 한 줄 정의

룰메이트는 사용자가 직접 정한 규칙으로 매일 종목을 걸러 ‘내 조건 충족 종목’를 보여주고, 관련 공시·뉴스를 빠르게 알려주고, 계획과 실제 매매를 매매일지에 남겨 규칙을 고쳐 나가도록 돕는 도구예요. 주문과 자동매매는 하지 않아요. 주문은 사용자가 증권 앱에서 직접 해요.

2. 배경과 문제

  • 개인 투자자는 기준 없이 그날 분위기로 사고팔다가 손실을 키우는 경우가 많아요.
  • 경쟁 퀀트·백테스트 도구는 지표가 많지만 이름이 전문용어 그대로예요(예: ‘분기EPS성장률(QOQ)’). 설명도 또 다른 용어로 풀어서 비전문가가 쓰기 어려워요.
  • 규칙을 세워도 실제 매매 결과와 연결해 돌아보는 장치가 없어서 규칙이 나아지지 않아요.

3. 목표와 하지 않는 것

목표

  • 비전문가도 쉬운 말로 된 조건을 골라 10분 안에 첫 규칙을 만들 수 있어요.
  • 매일 규칙에 맞는 후보와 그 이유(조건별 충족·감점)를 한눈에 볼 수 있어요.
  • 계획 → 산 기록 → 판 기록을 3번의 탭으로 남기고, 규칙을 지켰는지 자동으로 확인해요.
  • 기록이 쌓이면 어떤 조건·행동이 결과와 관련 있는지 보여주고 규칙 수정으로 이어지게 해요.

하지 않는 것 (1차 출시 제외)

  • 자동매매, 증권사 주문 연동
  • 특정 종목 추천, 수익 보장 표현
  • 규칙 공유·랭킹·마켓플레이스
  • 나눠 팔기(부분 매도) 기록 — 판 기록은 전량 매도로 계산

4. 대상 사용자

유형규칙 만드는 방식기대하는 것
비개발자 (주 사용자)블록 — 조건을 골라 숫자만 넣어요쉬운 말, 기본값, 실수 방지
수식 사용자수식 — 엑셀처럼 한 줄씩 (예: 평소보다북적임 >= 3)빠른 입력, 형식 오류 안내
개발자스크립트 — 파이썬 문법 (keep / score 함수)자유도, 미래 참조 검사

세 방식은 같은 규칙을 다르게 보여줄 뿐이에요. 어느 방식으로 고쳐도 다른 방식에 같은 값이 반영돼요.

5. 디자인·문구 원칙

  • 토스 같은 직관성: 큰 숫자, 한 화면 한 가지 일, 해요체 한 문장(20자 안팎).
  • 무엇을 알려주는지로 이름 짓기: RSI → 과열 온도, 체결강도 → 사려는 힘, PER → 이익 대비 몸값.
  • 비교 기준과 함께: “1,240만주”보다 “평소보다 3.2배”.
  • 상태 단어: 수치 옆에 뜨거워요 / 보통이에요 / 식었어요 같은 3단계 라벨.
  • 원래 용어는 숨기되 지우지 않기: 작게 함께 표시하고, 설정에서 끌 수 있어요.
  • 사실만 말하기: ‘올랐어요/내렸어요’. 좋다·나쁘다 판단이나 권유 문구는 쓰지 않아요.
  • 색의 뜻: 상승·이익 빨강, 하락·손실 파랑(국내 관례), 조건 충족 초록, 감점·경고 노랑, 미충족·해당 없음 회색.
  • 시안 2종: A 라이트(왼쪽 메뉴) / B 다크(위쪽 메뉴). 기능과 내용은 같고 설정에서 바꿔요.

6. 핵심 사용 흐름

홈 상단 ‘룰메이트 쓰는 순서’ 단계 표시로 지금 어디쯤인지 보여줘요.

  1. 규칙 만들기 — 규칙 빌더에서 조건을 고르고 숫자를 넣어요.
  2. 미리보기 — 지난 거래일 데이터로 후보가 어떻게 나오는지 바로 봐요.
  3. 저장 — 버전이 올라가고(v3 → v4) 결과 화면이 새 버전 기준으로 바뀌어요.
  4. 후보 확인 — 홈·내 조건 충족 종목에서 점수 순 후보와 이유를 봐요.
  5. 계획 계산 — 살 가격·끊기·챙기기를 정하면 살 수량을 계산하고 계획을 저장해요.
  6. 일지 기록 — 증권 앱에서 사고판 뒤 ‘샀어요’ → ‘팔았어요’로 실제 가격을 남겨요.
  7. 규칙 고치기 — ‘기록에서 찾은 것’을 보고 규칙 빌더에서 조건을 바꿔 비교해요.

7. 메뉴 구조

메뉴역할
홈쓰는 순서, 오늘 손익, 들고 있는 종목, 내 조건 충족 종목 N, 방금 온 알림
내 조건 충족 종목후보 목록, 차트, 왜 조건에 맞았나요, 매매 계획 세우기
알림공시·뉴스 소식·움직임 감지·내 규칙·보유 종목 알림 목록
매매일지기록할 게 있어요, 성적 요약, 기록에서 찾은 것, 매매 기록
규칙 빌더규칙 선택·생성, 블록/수식/스크립트, 4단계 설정, 미리보기, 규칙 점검
설정화면(A/B·원래 용어), 내 조건 충족 종목 개수, 알림 받기, 용어집

‘지금 기준 규칙’은 A에서는 왼쪽 메뉴 하단, B에서는 상단 메뉴 오른쪽의 셀렉트박스로 바꿔요. 결과 화면은 저장된 버전만 반영해요.

8. 화면별 기능 요구사항

P0 = 1차 출시 필수, P1 = 1차 권장, P2 = 이후

8.1 홈

  • P0 쓰는 순서 7단계 진행 표시와 다음 할 일 버튼
  • P0 오늘 손익(실현), 하루 손실 한도·연속 손실·오늘 매매 횟수 막대
  • P0 들고 있는 종목: 평가손익, 끊기~챙기기 가격 바, ‘팔았으면 기록하기’. 계획만 세운 종목은 ‘샀어요’
  • P0 내 조건 충족 종목 N: 순위·이름·한 줄 이유·점수·가격. 5개씩 ‹ › 화살표로 넘김
  • P1 방금 온 알림 3건

8.2 내 조건 충족 종목

  • P0 후보 목록(점수 높은 순, 설정한 개수만큼). 목록 안에서만 스크롤
  • P0 한 줄 이유: 충족 조건으로 자동 생성(예: “평소보다 5.6배 북적이면서 오늘 평균 단가보다 위에 있어요”)
  • P0 차트(선/캔들): 평균 단가선, 조건이 맞은 지점(초록)·감점 지점(노랑) 표시, 끊기·살 가격·챙기기 선
  • P0 왜 조건에 맞았나요: 합계 점수, 조건별 기여 막대, 조건마다 ✓/✕/! 와 현재값·상태 단어·기준
  • P0 내 계획 계산해 보기: 살 가격·끊기·챙기기 입력 → 내 손실 한도 기준 최대 수량, 필요 금액, 잘못되면/잘되면 금액, 손익비와 내 기준 통과 여부
  • P0 계획 진행 표시(계획 저장 · 산 기록 · 판 기록)와 단계에 맞게 바뀌는 버튼

8.3 알림

  • P0 분류: 공시 소식 · 뉴스 소식 · 움직임 감지(노랑) · 조건 충족 · 계획 가격 · 시스템
  • P0 필터: 전체 / 공시·뉴스 소식 / 움직임 감지 / 내 규칙 / 보유 종목
  • P0 알림 카드: 종목·등락·보유 중 표시, ‘소식이 먼저 떴어요 / 주가가 먼저 움직였어요’, 쉽게 말하면 설명, 출처
  • P0 토스트 팝업(6초 뒤 자동으로 닫힘)
  • P1 ‘뉴스는 주가가 먼저 움직인 뒤 나오는 경우가 많아요’ 상시 안내

8.4 매매일지

  • P0 ‘기록할 게 있어요’: 계획만 세운 종목(안 샀어요 / 샀어요), 보유 종목(지금 팔면 손익 / 팔았어요)
  • P0 산 기록: 실제 산 가격·수량(계획 가격·지금 가격, 계획대로·절반 빠른 버튼), 계획과 차이 즉시 표시
  • P0 판 기록: 판 가격(챙기기·끊기·지금 빠른 버튼), 손익 즉시 계산, 규칙 지킴 자동 확인, 한 줄 느낌·메모(선택)
  • P0 안 샀어요: 이유 4가지 중 선택 → ‘안 산 계획’으로 저장
  • P0 성적 요약: 기록한 매매, 이긴 비율, 합계 손익, 규칙 지킨 비율
  • P0 매매 기록 표: 날짜·종목·규칙 버전·그때 조건(막대+요약)·결과·규칙. 펼치면 차트, 계획/실제, 확인 결과, 메모
  • P1 기록에서 찾은 것: 조건·행동별 성적 비교 → ‘규칙 고치러 가기’ (시안은 ‘큰 내린 봉’ 1가지만 계산)

8.5 규칙 빌더

  • P0 편집할 규칙 셀렉트박스, ‘+ 새 규칙’(빈 규칙 / 예시 필터 2개 — 숫자 비움, 성과 보증·권유 아님 고지), 이름 수정, 버전 표시(저장됨 / 수정 중 / 미완성)
  • P0 방식 선택: 블록 · 수식 · 스크립트(미리보기에 적용, 블록 기준으로 되돌리기)
  • P0 1단계 종목 거르기 / 2단계 점수 매기기(조건별 ±5점, 감점 가능)
  • P0 조건 추가 창: 검색, 7개 묶음 탭, 쉬운 이름·설명·화면 예시·원래 용어, 68개 조건
  • P0 3단계 마지막 확인: 여기서 끊기(산 가격 % · 평균 단가 아래 · 따라 올라가기), 여기서 챙기기(걸 돈의 몇 배 · 산 가격 %), 걸 돈 대비 벌 돈 최소, 후보 기준 점수, 한 번에 잃어도 되는 돈
  • P0 4단계 알림 설정
  • P0 미리보기: 샘플→거르기 통과→최종 후보 개수, 상위 5개(조건 막대+요약), 1위 차트, 결과 0개일 때 원인과 완화 버튼
  • P0 규칙 점검: 빈칸, 범위 밖 숫자, 모순 조건, 중복, 점수 기준 초과, 조건 과다(과최적화), 수식 오류, 미래 참조
  • P0 저장: 공용 ‘저장’ 버튼 하나. 누르면 다음 버전(v3 → v4)으로 저장되고, 고칠 곳이 있으면 안내만 해요
  • P0 조건을 추가하면 기준 숫자와 점수는 빈칸(점수?)으로 들어가고 사용자가 직접 정해요. 3단계 숫자도 직접 입력 + −/+ 조정

8.6 설정

  • P0 화면: A 라이트 / B 다크 미리보기 카드, 원래 용어 함께 보기
  • P0 계산에 쓸 내 투자금: 직접 입력(계좌 연동 없음), 최대 수량 계산에만 사용. 비우면 수량 계산 안 함
  • P0 내 규칙 관리: 고치기 · 복제 · 지우기(확인 후 삭제, 일지 기록은 유지, 마지막 1개는 삭제 불가)
  • P0 내 조건 충족 종목 개수: 3 / 5 / 10 / 15개, 실제 맞은 개수 안내
  • P0 알림 받기: 점수 기준(점수 조절), 계획 가격, 공시·뉴스 — 바꾸면 바로 적용, 규칙 버전은 그대로
  • P0 용어집 창: 검색, 7개 묶음 + 색의 뜻 탭, 쉬운 설명·화면 예시·원래 용어·수식/스크립트 이름

9. 조건 라이브러리

‘단기 트레이딩 지표 쉬운 용어 사전’을 기준으로 68개 조건을 7개 묶음으로 나눴어요. 모든 조건은 거르기와 점수 매기기 양쪽에 쓸 수 있어요(지금 가격·주의 표시 빼기는 거르기 전용).

묶음대표 조건 (쉬운 이름 · 원래 용어)
가격·출렁임어제보다(등락률), 출발 점프(시가 갭), 오늘 범위 중 위치, 평소 출렁임(ATR), 오늘 평균 단가(VWAP), 1년 최고가까지
거래·수급오늘 몰린 돈(거래대금), 평소보다 북적임(RVOL), 사려는 힘(체결강도), 큰손 거래, 누가 사고 있나(외국인·기관), 내릴 쪽에 건 비중(공매도)
차트 신호과열 온도(RSI), 흐름 가속도(MACD), 평소 가격대 벗어남(볼린저밴드), 오르는 흐름(정배열), 흐름이 위로 바뀜(골든크로스), 천장 뚫음, 큰 내린 봉(장대음봉)
기간 흐름한 달 / 3달 / 반년 / 1년 동안(수익률), 요즘 큰손 매수
실적·몸값내 돈으로 버는 힘(ROE), 빚 비중(부채비율), 작년보다 매출(YoY), 다시 벌기 시작(흑자 전환), 이익 대비 몸값(PER), 배당으로 받는 비율
회사 정보회사 크기(시가총액), 상장한 지, 실제로 거래되는 주식(유통주식비율), 주의 표시 빼기
시장·이벤트오늘 시장 분위기, 같이 움직이는 무리, 무리의 선두(대장주), 시장보다 얼마나 셌나(상대강도), 잠깐 멈춤(VI), 회사 발표(공시), 화제성

12. 계산 규칙

  • 점수: 거르기를 통과한 종목에서, 맞은 조건의 점수(감점 포함)를 합해요. 후보 기준 점수 이상 + 걸 돈 대비 벌 돈 최소 이상만 후보예요. 점수가 같으면 ‘평소보다 북적임’이 큰 순서예요.
  • 거래 비용: 세금·수수료 왕복 0.23%를 모든 손익에 포함해요.
  • 최대 수량: (내 투자금 × 한 번에 잃어도 되는 돈 %) ÷ (살 가격 − 끊기 가격 + 살 가격 × 0.23%). 계좌 금액을 넘지 않게 맞춰요. 기본은 계좌의 1%예요.
  • 끊기 가격: 산 가격 × (1 − 끊기 폭) / 오늘 평균 단가 × 0.995 / 따라 올라가기(최고가 대비 끊기 폭). 가격은 호가 단위로 맞춰요.
  • 챙기기 가격: 살 가격 + (살 가격 − 끊기 가격) × 벌 돈 배수 / 산 가격 × (1 + 챙기기 폭).
  • 규칙 지킴 판정: ① 산 가격이 계획보다 1% 넘게 비싸지 않음 ② 계획 수량 이하 ③ 끊기 가격 아래로 0.3% 넘게 내려가 팔지 않음. 셋 다 맞으면 ‘지켰어요’예요.
  • 미리보기 기준: 지난 거래일 장 마감 데이터. 저장 전 변경은 결과 화면에 반영하지 않아요.

13. 데이터 요구사항

  • 실시간 시세·호가·체결(1분/5분 봉), 투자자별 매매동향, 프로그램 매매, 공매도·신용 잔고
  • 재무(분기 실적, ROE·부채비율 등), 밸류에이션(PER·PBR·PSR·배당)
  • 공시(DART), 뉴스·언급량, VI·투자경고 등 거래소 이벤트
  • 운영사 자체 점수·순위(종합·흐름·체력·업종·가격 위치 점수)는 1차 출시에서 제공하지 않아요
  • 데이터 지연 감지와 재계산 로그 (시스템 알림에 사용)

14. 문구·법적 제약

  • 메뉴 이름은 ‘오늘의 후보’ 대신 ‘내 조건 충족 종목’을 써요. 공시·뉴스는 호재·악재로 판단하지 않고 ‘공시 소식 / 뉴스 소식’으로만 분류해요. 조건 예시 수치는 모두 ‘예시 ·’를 붙여 작은 회색 글씨로 보여줘요.
  • ‘추천’, ‘수익 보장’, ‘사세요/파세요’ 같은 권유 표현을 쓰지 않아요. 후보는 ‘내 규칙에 맞는 종목’이에요.
  • 필수 고지 3문장: “정보제공·학습용 도구이며 투자판단과 책임은 이용자에게 있음”, “금융투자상품의 매수·매도를 권유하지 않음”, “자동주문·일임 없음”. 첫 사용 안내 창, 설정 › 약관·고지, 모든 화면 하단에 같은 문장을 써요.
  • ‘신호·픽·탑픽·매수/매도 타이밍’ 같은 단어를 쓰지 않아요. 알림은 ‘조건 충족 알림’처럼 정보 전달로만 써요.
  • 운영사 점수·순위·랭킹, 예시 필터 간 성과 비교, 투자성향·재무상황 수집, 모델 포트폴리오·비중 제안·리밸런싱 알림은 제공하지 않아요.
  • 요금은 ‘소프트웨어·데이터 이용료’로 표기하고, 1:1 종목 상담·유료 리딩·폐쇄방은 운영하지 않아요. 광고·랜딩 페이지에도 추천·보장 뉘앙스를 쓰지 않아요.
  • 성과·백테스트를 보여줄 때는 가정·기간·수수료·슬리피지·표본 수를 함께 적고, 미래 수익을 보장하지 않는다는 문장을 굵게 고지해요.
  • 면책 고지 위치: 모든 화면 하단, 왼쪽 메뉴 하단(A), 후보 목록 아래, 계산기 아래, 기록 창 하단(“주문은 증권 앱에서 직접 해 주세요”).
  • 과거 결과는 앞으로도 같다는 뜻이 아님을 결과·검증 화면에 함께 적어요.
  • 출시 전 핀테크지원센터 또는 금융감독원·금융위원회 사전컨설팅으로 자문·일임 신고 대상인지 확인받아요. 특히 예시 필터, 성과 표시, 알림 문구에 대한 의견을 요청해요.

15. 성공 지표 (제안)

  • 첫 규칙 저장까지 걸린 시간, 가입 후 첫 규칙 저장 비율
  • 주간 활성 사용자 중 내 조건 충족 종목를 3일 이상 본 비율
  • 계획 저장 → 산 기록 → 판 기록 완료 비율 (기록 완주율)
  • 규칙 지킨 비율의 변화, 기록 후 규칙을 고친 비율
  • 알림 클릭률, 용어집·원래 용어 켜기 사용률

16. 다음 단계와 열린 질문

다음 단계

  • ‘기록에서 찾은 것’ 고도화: 모든 조건·행동·한 줄 느낌·안 산 계획별 비교, 최소 기록 수(예: 10번) 미만이면 결론 보류
  • 안전장치 설정 화면: 하루 손실 한도, 연속 손실 시 쉬기, 하루 매매 횟수 (지금 홈 위젯 값은 고정)
  • 과거 데이터 검증 화면(배운 기간 vs 확인 기간, 과최적화 경고)과 성과 용어(이긴 비율, 가장 크게 빠졌던 폭 등)
  • 나눠 팔기 기록, 첫 사용자 온보딩(규칙 템플릿 고르기), 실데이터 연동

열린 질문

  • 주 투자 기간: 장중 단타 중심으로 둘지, 스윙·중장기 지표 묶음을 기본 노출할지
  • 운영사 자체 점수를 이후에 넣을지, 넣는다면 계산식 공개 방식
  • 기본 규칙 템플릿을 몇 개, 어떤 이름으로 제공할지 (숫자는 비워 두는지 포함)
  • 모바일 지원 범위 (지금 시안은 PC 우선)
